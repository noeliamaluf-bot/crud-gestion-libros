# CRUD de Gestión de Libros

### Requisitos
Este proyecto utiliza librerías nativas de Python (Tkinter y sqlite3), 
por lo que no requiere instalar dependencias adicionales.

### Cómo ejecutar el proyecto
1. Descarga o clona los archivos en una misma carpeta.
2. Abre la terminal en esa carpeta.
3. Ejecuta el comando:
   python main.py
